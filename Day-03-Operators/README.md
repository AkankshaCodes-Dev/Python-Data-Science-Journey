## 💻 Arithmetic Operators

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

### Important Differences

```text
/   → Division
//  → Floor Division
%   → Remainder
**  → Exponent
```

For example:

```python
print(17 / 5)    # 3.4
print(17 // 5)   # 3
print(17 % 5)    # 2
print(2 ** 3)    # 8
```

## 🔍 Assignment vs Comparison

```text
=   → Assigns a value
==  → Checks whether two values are equal
```

Example:

```python
x = 10

print(x == 10)
```

## 🧠 Logical Operators

Python provides three main logical operators:

```text
and
or
not
```

They are used to combine or modify conditions.

Example:

```python
age = 20

print(age >= 18 and age <= 25)
```
