# Day 2 - Variables and Data Types 🐍

## 📚 Topics Learned

- Variables
- Assignment operator `=`
- Integer `int`
- Float `float`
- String `str`
- Boolean `bool`
- `type()` function

## 💻 Example

```python
name = "Akanksha"
age = 20
height = 5.0
is_learning = True

print(name)
print(age)
print(height)
print(is_learning)
```

## 🔍 Checking Data Types

```python
print(type(name))
print(type(age))
print(type(height))
print(type(is_learning))
```

Example data types:

```text
name → str
age → int
height → float
is_learning → bool
```
